Homelab

Home infrastructure that earns its claims.

My home setup is part useful household infrastructure and part proving ground for agent-operated systems. Public notes are being reshaped into this site; the old homelab GitHub Pages site is intentionally unpublished.

Current shape

Automation and entity hub tying devices, sensors, and dashboards together.

Wall-mounted Raspberry Pi dashboard for family-facing data.

Edge and monitoring node for observability, exporters, and experiment work.

Frigate

Camera and detection experiments, including companion app work.

Local LLMs

Private inference and agent fallback paths on local machines.

Writing rule

Old build notes are useful, but live claims only belong on a page when they can be checked again. I prefer audit snapshots, setup guides, and small verified notes over aspirational architecture diagrams.
