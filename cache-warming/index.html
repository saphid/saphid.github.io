Cost field note · 24 September 2026

Keep the cache warm.

Coding agents build huge contexts. Then you go to lunch, the prompt cache expires, and your next message pays to write the whole thing again.

Alex Southwell3 minute read

The fix is a keep-alive. Just before the cache expires, resend the thread's last request byte for byte, with max_tokens: 0. No answer comes back. The provider reads the cached prefix, and that read resets the expiry clock. A read costs a small fraction of a write.

The orange line jumps once the cache expires. The blue staircase climbs by one cheap read per ping. Until the blue line catches the orange, keeping the cache warm is cheaper.

When it stops paying

Context size cancels out. Break-even depends only on how much cheaper a read is than a write, and how often you ping.

On a 1-hour cache, Fable 5.1 reads are one eightieth the price of a write. That buys three days of pings. A 5-minute cache needs a ping every few minutes, so it runs out much sooner.

The catch: you don't always come back

That blue staircase is also what a finished thread costs. A keep-alive can't tell a lunch break from a closed task, so it keeps paying for threads you've abandoned. Most breaks that matter are short: lunch, a meeting, a review. Overnight gaps are where abandoned threads pile up.

So set a cutoff. A few hours catches the breaks worth catching, and stops paying for the rest. Skip small contexts too, where a rewrite costs pennies anyway.

What pings can't fix

A ping keeps the old prefix alive. It can't help once the prefix changes, whether from compaction, an edited system prompt, a model switch, or new tool definitions. Those misses need fixing in how the context is built.

Building it

  • Save the exact bytes of each idle thread's last request.
  • Replay them just before expiry, asking for zero output.
  • Stop after a few hours, and skip small contexts and subagents.
  • Keep pings out of thread history. They're cache traffic, not turns.
  • Log each miss as expiry or invalidation, so you tune the right thing.

Prices per million tokens, from Anthropic's rate card: Fable 5.1 reads $0.25, 5-minute writes $12.50, 1-hour writes $20. Opus 5.5 reads $0.20, writes $5 and $8. Sonnet 5 reads $0.20, writes $2.50 and $4. OpenAI's GPT-5.6 and later bill writes at 1.25x input and reads at 0.1x, with a 30-minute cache.
