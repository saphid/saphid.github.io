Cost field note · 24 September 2026

Keep the cache warm.

Coding agents build huge contexts. Then you go to lunch, the prompt cache expires, and your next message pays to write the whole thing again.

Alex Southwell3 minute readTwo weeks of real transcripts

The fix is a keep-alive. Just before the cache expires, resend the thread's last request byte for byte, with max_tokens: 0. You get no answer back. The provider reads the cached prefix, and that read resets the expiry clock.

When it pays

Every ping is a cache read. At some point the pings add up to more than the rewrite they're preventing. Context size cancels out, so the break-even point depends only on the price ratio and how often you ping.

So a keep-alive needs a cutoff. Past it, stop pinging and take the cold write.

What it would have saved

I replayed two weeks of my own Claude Code and Codex transcripts, September 9 to 23, with a 24-hour cutoff.

Most of the saving came from a few long engineering threads with contexts of several hundred thousand tokens, left idle for one to four hours. Codex barely moved. Its contexts are cheaper and I'm on a flat-rate plan, so even the $8.73 is a rate-card figure, not money I'd get back.

Don't just lengthen the cache

Claude offers a 1-hour cache, but writing to it costs 2x input instead of 1.25x. Every new token in a growing thread pays that higher price. Forcing one cache length on everything made spend go up.

What pings can't fix

A ping keeps the old prefix alive. It can't help once the prefix itself changes, whether from compaction, an edited system prompt, a model switch, or new tool definitions. In my data that was the small slice.

Building it

  • Save the exact bytes of each idle thread's last request.
  • Replay them just before expiry, asking for zero output.
  • Stop at the break-even cutoff, and skip contexts too small to be worth it.
  • Keep pings out of thread history. They're cache traffic, not turns.
  • Log each miss as expiry or invalidation, so you tune the right thing.

For a big thread you come back to after lunch, a few cents of pings saves a few dollars of rewrite.

Claude figures are estimated cash cost. Codex figures use API list prices. Break-even assumes reads at 0.1x input, writes at 1.25x (5-minute and OpenAI) or 2x (1-hour), and pings every 4, 28, and 55 minutes. Hover any bar for its value.
