PA Live support

PA Live is the iPhone and iPad app for a personal assistant that you host yourself. You can call or text its bots, read the pages they make, follow background jobs, and approve or deny requests before anything happens. PA Live is not a hosted service: it needs a PA Live server running on a Mac that you control.

Pair your device

On first launch, pair PA Live with your server. Scan the pairing code your server shows, paste a pairing link, or type the server address and code. Pairing links are single-use and expire quickly. If one has expired, create a new one on your server. Allow Local Network access when asked so the app can reach your server, and Microphone access if you want to use voice calls.

Connection help

Check that your server is running and that this device can reach it over your network or VPN. If calls fail but typed messages work, check that the voice service configured on your server has access and credit. Keep pairing links and codes private.

Get help

Email saphid@gmail.com with the app version, iOS version, and steps that reproduce the problem. Do not send passwords, tokens, pairing links, server addresses, or private conversations.
